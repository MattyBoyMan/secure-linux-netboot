Your keyboard shortcuts

What you did on Windows, and how to do it here. The Meta key is the Windows key. Print this page with Ctrl+P.

Main laptop (KDE Plasma)

MetaOpen the app launcher (Start menu). Just type.
Alt+SpaceSearch everything (KRunner)
Meta+EFiles (Dolphin)
Meta+LLock the screen
Meta+VClipboard history
Meta+.Emoji picker
Print ScreenScreenshot (Spectacle)
Meta+WSee all windows (like Task View)
Meta+← / →Snap a window to half the screen
Alt+TabSwitch windows
Alt+F4Close a window
Ctrl+Alt+TTerminal (Konsole)

Older PCs (Xfce)

Menu buttonOpen the app menu (bottom or top panel)
Alt+F2Find and run an app by name
Ctrl+Alt+LLock the screen
Print ScreenScreenshot
Drag to an edgeSnap a window to half the screen
Alt+TabSwitch windows
Alt+F4Close a window
Ctrl+Alt+TTerminal

Everywhere

Ctrl+C / V / X / ZCopy / paste / cut / undo
Ctrl+T / Ctrl+WNew tab / close tab (LibreWolf)
Ctrl+Shift+TReopen the tab you just closed
Ctrl+Shift+PPrivate window (LibreWolf)
Ctrl+Shift+LFill in your password (Bitwarden extension)
Task ManagerOpen Mission Center from the menu
Error you don't get?Copy it, open Explain This Error

Lost? Open the START-HERE guide on your Desktop, or type what you're looking for into the app launcher: the guide's pages show up in the search. Shortcuts can be changed in System Settings > Keyboard > Shortcuts.
