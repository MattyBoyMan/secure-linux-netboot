THE FLIPPER ZERO BadUSB SCRIPTS - one-button helpers
====================================================

These are for computers that are ALREADY installed with the Complete Secure
Linux Package (from the USB stick or over the internet - the installed system
is the same). The Flipper pretends to be a KEYBOARD and types one command;
the computer does the work.

  repair_setup.txt     re-check and repair this computer's Secure Linux setup
  health_check.txt     run the full hardware health check
  open_toolbox.txt     open the Secure Linux Toolbox
  usb_fixer.txt        open image-first USB diagnosis, recovery and repair
  usb_creator.txt      open Linux USB Installer Creator - Turn any blank USB into a Linux installer
  flipper_companion.txt  open the Flipper Companion backup and SD-management menu
  status_window.txt    open the Status window (health + fix-it buttons)
  install_updates.txt  install all updates (asks for the login password)

Use: copy the .txt files to the Flipper's SD card under /badusb/ (qFlipper or
the Flipper app does this), plug the Flipper into the computer, open
Bad USB on the Flipper, pick a script, press Run.

The other job this Flipper can do is BOOTING a computer to install Secure
Linux over the internet (the Boot2Flipper app) - see README-FLIPPER.txt
one folder up.

Only ever use these on your own computers. The scripts never type passwords.
